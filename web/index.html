Set up the knob for app switching

This saves F13–F19 on the knob, one key per part, which Knob Agent turns into each app's shortcut. You only need to do it once. Plug the knob in with the USB-C cable and use Google Chrome or Microsoft Edge; Safari and apps' built-in browsers can't talk to USB devices.
